# Array dan ArrayList - PBO 2026

Repository ini berisi source code program Java untuk memenuhi tugas mata kuliah Pemrograman Berorientasi Objek (PBO) dengan materi Array dan ArrayList.

## 📚 Materi

- **Array**: Struktur data untuk menyimpan beberapa elemen dengan tipe data yang sama dalam satu variabel dengan ukuran yang telah ditentukan.
- **ArrayList**: Struktur data dalam Java yang dapat menyimpan kumpulan elemen dan memungkinkan ukuran koleksi bertambah atau berkurang secara dinamis.
- **Perbedaan Array dan ArrayList**: Memahami perbedaan penggunaan, ukuran, dan pengelolaan data pada Array dan ArrayList.

## 🛠️ Teknologi yang Digunakan

- Java
- Java Development Kit (JDK)
- Visual Studio Code

## 🎯 Tujuan Tugas

Tugas ini bertujuan untuk memahami konsep Array dan ArrayList serta menerapkan penggunaannya dalam bahasa pemrograman Java untuk mengelola kumpulan data.

## ▶️ Cara Menjalankan Program

1. Clone repository ini ke komputer menggunakan perintah:

   ```bash
   git clone https://github.com/azaliasakila/Array-dan-Arraylist-PBO26.git
   ```

2. Buka folder repository di Visual Studio Code.
3. Pastikan Java JDK sudah terpasang.
4. Buka file Java yang ingin dijalankan.
5. Jalankan program dengan menekan tombol **Run**.
